# Simple Student Management System

A beginner-friendly frontend project built with HTML, CSS and Vanilla JavaScript.

## How to run
1. Extract the ZIP file.
2. Open the `student_management_simple` folder.
3. Open `index.html` in Chrome or use VS Code Live Server.

## Features
- Dashboard summary
- Add, edit, delete and search students
- Mark daily attendance
- Add tasks and update task status
- Record positive and negative activity points
- Save data in browser Local Storage
- Load sample data

## Notes
This is a simplified learning version of the institute assignment. It does not include every advanced requirement from the original 38-page specification, such as detailed analytics, full reports, image uploads, or backup/restore.
Data is saved only in the browser and device where the app is used. Clearing browser data may remove it.
